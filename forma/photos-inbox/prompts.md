# Forma — image prompts

Every prompt ends with the same **style block**, so all the images look like one
practice's work. Paste each prompt as-is. If your generator has a separate
"negative prompt" field, paste the negative line there; otherwise leave it out.

**Negative (all images):** people, faces, text, letters, logos, watermark, signage,
cars, clutter, oversaturated colors, HDR look, fisheye distortion, CGI plastic look

**Save each result with the file name shown**, then drop it in this folder.

## Architect portrait (vertical 4:5): `portrait.jpg`

> **Recommended: use a real photo of the architect.** Clients hire the person, and a
> generated face on a real practice's site misleads them. If you need a stand-in for
> now, this prompt avoids showing a face:

```
An architect working at a large drafting table in a calm, daylit studio, seen from behind and slightly to the side, face not visible, sleeves rolled up, sketching on tracing paper with a pencil. Shelves with white card models in the soft background. Photorealistic photograph, full-frame camera, 50mm lens, shallow depth of field. Calm, restrained, editorial magazine quality. Muted natural colors, deep charcoal shadows, warm window light. No text.
```
