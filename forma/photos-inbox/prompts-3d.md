# Forma: 3D miniature prompts (scroll-world style, with little figures)

Five floating 3D miniatures, one per phase of the walkthrough. They must look like **one
world**: same angle, same light, same background, same colours. To get that:

1. Every prompt below starts with the **same style paragraph**. Don't edit it.
2. Generate **`island-home`** first. When you like it, generate the other four **in the same
   ChatGPT conversation**, and attach that first image each time with:
   *"Match the style, angle, lighting, background and colours of this image exactly."*
3. Use one tool for all five (all ChatGPT), since mixing tools changes the look.
4. Ask for **landscape 3:2**, the largest size available.

Each scene has tiny clay figures doing that phase's work, so the AI video can bring them
to life later. Keep them small and simple, without detailed faces.

Save each result with the file name shown and put them in the `forma/photos` folder.
